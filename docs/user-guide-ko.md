# PRE-GLOW 0.1.3 베타 사용설명서

PRE-GLOW는 보컬, 기타, 신스 같은 소리에 공간감과 잔향을 더하는 리버브 플러그인입니다.

## 1. 내 환경에 맞는 파일 고르기

이번 베타 ZIP은 Apple Silicon(M 시리즈) Mac용입니다. Apple 메뉴 → **이 Mac에 관하여**에서 칩을 확인할 수 있습니다. 아래에서 사용할 형식 하나를 받아 압축을 풉니다.

| 사용 환경 | ZIP 이름 끝부분 | 설치 방법 |
| --- | --- | --- |
| Logic Pro | `-AU.zip` | `pre-glow.component`를 `~/Library/Audio/Plug-Ins/Components/`에 복사 |
| Ableton Live, Cubase 등 VST3 지원 DAW | `-VST3.zip` | `pre-glow.vst3`를 `~/Library/Audio/Plug-Ins/VST3/`에 복사 |
| DAW 없이 오디오 입력으로 확인 | `-Standalone.zip` | `pre-glow.app`을 응용 프로그램 폴더에 옮겨 실행 |

Finder에서 **⌘⇧G**를 누르면 설치 경로를 붙여넣을 수 있습니다. 폴더가 없으면 상위 폴더에서 만들어 주세요. 설치 후 DAW를 완전히 종료했다가 다시 열고 오디오 트랙의 이펙트 목록에서 **PRE-GLOW**를 찾으세요. VST3가 안 보이면 DAW의 플러그인 설정에서 VST3 스캔이 켜져 있는지 확인하고 다시 스캔하세요.

이 베타는 Apple 공증을 받지 않았습니다. macOS나 DAW가 로딩을 차단하면 표시된 메시지를 개발자에게 보내 주세요. Intel Mac과 Windows용 파일은 이번 패키지에 포함되어 있지 않습니다.

## 2. 첫 리버브 들어보기

1. DAW에서 보컬이나 악기 클립을 재생하고 같은 트랙에 **PRE-GLOW**를 이펙트로 추가합니다. Standalone에서는 오디오 설정에서 입력과 출력을 선택하고 소리를 넣어 보세요. 마이크 입력을 쓸 때는 헤드폰을 사용하세요.
2. 스펙트럼 아래 **Presets**를 열고 **Factory → Hall → Load**를 선택합니다. 짧은 공간감은 **Room**, 길고 넓은 잔향은 **Cloud**로 비교해 보세요.
3. **Decay**를 돌려 잔향 길이를 바꾸고 **Wet**으로 잔향의 양을 조절합니다. 원음은 **Dry**로 조절합니다. 센드/리턴 트랙에 꽂았다면 Dry를 0으로 두고 리턴 레벨로 섞어 보세요.
4. **Shimmer On**을 켜고 Advanced의 **Shimmer Mix**를 올려 피치가 바뀐 잔향을 들어 보세요. 소스가 재생되는 중에 **Freeze**를 켜면 그때의 잔향이 유지됩니다. 원음은 계속 들리고, Freeze를 끄면 새 소리가 다시 잔향에 들어갑니다.

## 3. 리버브의 기본 소리 만들기

제목 아래 **Basic** 버튼을 누르면 **Advanced**로 전환됩니다. Advanced에서 설정을 바꾼 뒤 Basic으로 돌아가도 적용된 소리는 유지됩니다.

| 컨트롤 | 역할과 사용법 |
| --- | --- |
| **Character / Character B** | A와 B에 각각 리버브 캐릭터를 지정합니다. 짧은 공간감은 Room, 넓은 공간은 Hall, 매끈한 보컬 잔향은 Plate, 퍼지는 패드는 Cloud에서 시작해 보세요. Cathedral과 Void도 같은 소스를 재생하며 비교해 보세요. |
| **Reverb A/B** | A와 B의 잔향을 섞습니다. A 100%에서 B 쪽으로 움직이며 공간의 질감이 어떻게 변하는지 들어보세요. |
| **XY Morph** | 가로축으로 A/B, 세로축으로 Wet을 동시에 조절합니다. 위로 갈수록 잔향이 커집니다. A/B와 Wet 노브에도 같은 값이 반영됩니다. 패드를 더블 클릭하면 두 축이 중앙으로 갑니다. |
| **Decay** | 잔향이 사라지는 시간을 조절합니다(0.1–120초). 보컬의 다음 단어가 묻히면 줄이고, 길게 이어지는 패드에는 늘려 보세요. |
| **Dry / Wet** | Dry는 원음, Wet은 효과음 레벨입니다. 두 값은 독립적입니다. 트랙에 직접 꽂았다면 Dry로 원음을 유지하며 Wet을 올리세요. 센드 리턴에서는 Dry를 0%로 두세요. |
| **Damping** | 리버브가 반복될 때 고역이 줄어드는 정도입니다. 올리면 시간이 지날수록 잔향이 어두워져 치찰음이나 심벌이 덜 두드러집니다. |
| **Early Width / Late Width** | Early는 소리 직후의 반사음, Late는 뒤에 이어지는 잔향의 스테레오 폭을 조절합니다. 각각 0%는 중앙, 100%는 기본 폭, 200%는 더 넓은 설정입니다. 원음 위치를 선명하게 두고 싶다면 Early를 좁히고 Late만 넓혀 보세요. |

### Low Cut과 Multiband

**Low Cut**은 설정 주파수 아래의 저역을 줄입니다. **Reverb Input**은 리버브에 들어가기 전에 저역을 줄여 저음이 잔향을 덜 자극하게 합니다. **Wet Output**은 만들어진 효과음의 저역을 줄입니다. 두 위치 모두 Dry 레벨과 원음은 그대로입니다. **Low Cut Off**로 비교할 수 있습니다.

**Multiband**는 잔향을 Low, Mid, High 세 대역으로 다룹니다. **Low / Mid**와 **Mid / High**는 대역을 나누는 주파수입니다. 기본값은 250 Hz와 4 kHz입니다. 경계를 옮기면 아래 설정이 영향을 주는 주파수 범위도 바뀝니다.

| 대역별 컨트롤 | 역할 |
| --- | --- |
| **Band Decay** | 기본 Decay에 대한 대역별 배율입니다. 1×가 기본이고, Low를 0.6×로 줄이면 저역 잔향이 더 빨리 가라앉습니다. |
| **Feedback Damping** | 해당 대역이 리버브 안에서 반복될 때 추가로 감쇠하는 정도입니다. 값을 높이면 반복할수록 해당 대역이 덜 남습니다. |
| **Wet Level** | 효과음에서 들리는 해당 대역의 양입니다. 100%가 기본입니다. 저역 잔향의 시간은 마음에 들지만 너무 크게 들릴 때 Low Level을 낮춰 보세요. |
| **Shimmer Send** | 각 대역에서 피치 변환으로 들어가는 양입니다. 저음이 변환되어 뭉치면 Low Shimmer Send를 줄여 보세요. |
| **Modulation Depth** | 해당 대역 잔향의 움직임을 조절합니다. 0%에서 시작해 조금씩 올리면 정적인 잔향에 흔들림을 더할 수 있습니다. |

## 4. Shimmer로 음정이 바뀐 잔향 만들기

**Shimmer On**을 켜고 Advanced에서 **Shimmer** 패널을 엽니다. **Voice 1 → On**, **Pitch +12**, **Level 1.00**을 확인한 뒤 **Shimmer Mix**를 15–25%로 올려 보세요. 기본 프리셋은 Shimmer Mix가 0%라 스위치만 켜서는 피치 효과가 들리지 않습니다.

| Shimmer Routing | 신호가 지나가는 순서와 용도 |
| --- | --- |
| **Feedback** | 리버브의 소리를 피치 변환하고 일부를 다시 리버브로 보냅니다. **Feedback**과 보이스별 **Send**를 올리면 피치가 바뀐 소리가 다시 변환되며 잔향이 층층이 쌓입니다. 작은 값부터 올려 보세요. |
| **Post-Reverb** | 리버브에서 나온 소리를 피치 변환해 Wet 출력에 더합니다. 원래 리버브 뒤에 옥타브 잔향을 얹고 싶을 때 사용하세요. |
| **Pre-Reverb** | 입력을 먼저 피치 변환해 리버브에 보냅니다. 피치가 바뀐 음이 공간 안에서 함께 퍼집니다. |
| **Parallel** | 입력을 피치 변환해 Wet 출력에 더합니다. 원래 리버브와 피치 레이어를 나란히 들을 수 있습니다. |

최대 네 개의 보이스를 쓸 수 있습니다. 각 카드의 **On**은 소리를 켜고, **Show controls / Hide controls**는 조절부를 열거나 접습니다.

| 보이스 컨트롤 | 역할 |
| --- | --- |
| **Pitch** | 반음 단위로 음정을 이동합니다(−24~+24). +12는 한 옥타브 위, −12는 한 옥타브 아래, +7은 완전5도 위입니다. |
| **Fine (ct)** | 음정을 센트 단위로 미세 조정합니다. 100센트가 반음입니다. 두 보이스를 약간 다르게 맞추면 겹친 음에 움직임이 생깁니다. |
| **Level** | 해당 보이스의 음량입니다. On 상태라도 Level이 0이면 해당 보이스가 들리지 않습니다. |
| **Pan** | 보이스의 좌우 위치입니다. −1은 왼쪽, 0은 중앙, +1은 오른쪽입니다. |
| **Delay (ms)** | 해당 보이스가 들리기까지의 지연입니다(0–250 ms). 보이스마다 다르게 두면 레이어가 한꺼번에 몰리는 느낌을 줄일 수 있습니다. |
| **Tone (Hz)** | 피치 변환음의 저역 통과 필터 주파수입니다. 낮추면 밝고 거친 고역이 줄어듭니다. |
| **Send** | Feedback 모드에서 이 보이스를 리버브로 얼마나 돌려보낼지 정합니다. Level은 보이스 크기, Send는 그 보이스의 되돌림 양입니다. |

## 5. 잔향이 시작하고 유지되는 방식 바꾸기

| 기능 | 동작과 조절법 |
| --- | --- |
| **Freeze** | 켜는 순간까지 만들어진 잔향을 붙잡고 새 입력이 그 잔향에 들어가는 것을 차단합니다. Dry는 계속 들립니다. PRE-GLOW는 새 입력에서 생기는 리버브도 별도로 섞을 수 있어, Freeze를 켠 뒤에도 새 소리의 잔향이 들릴 수 있습니다. |
| **Infinite Decay** | 리버브의 감쇠 시간 설정을 600초로 늘리며 새 입력을 계속 받습니다. Damping은 계속 작동합니다. Freeze가 켜진 동안에는 Freeze가 우선하고, 끄면 선택한 Decay 모드로 돌아갑니다. |
| **Bloom** | 첫 반사음을 약하게 하고 후기 잔향이 입력에 반응해 자라도록 합니다. **Amount**는 효과량, **Attack**은 자라는 시간, **Release**는 반응이 가라앉는 시간입니다. **Shape**를 높이면 시작 부분이 더 부드러워집니다. |
| **Swell** | 입력이 감지 기준을 넘으면 Wet이 서서히 올라옵니다. **Time**은 올라오는 시간, **Sensitivity**는 작은 소리에도 시작되는 정도, **Curve**는 올라오는 모양입니다. 조용한 소스에서 반응이 없으면 Sensitivity를 올려 보세요. |
| **Reverse-like** | 새 어택을 감지할 때 Wet을 낮췄다가 다시 올려 역재생 리버브처럼 밀려오는 느낌을 만듭니다. **Rise**를 늘리면 올라오는 시간이 길어집니다. |
| **Ducking** | 원음이 클 때 Wet을 줄였다가 원음이 작아지면 복원합니다. **Threshold**는 작동 기준, **Amount**는 줄이는 정도, **Attack**은 줄어드는 속도, **Release**는 돌아오는 속도입니다. Amount가 0%면 스위치가 켜져 있어도 효과가 없습니다. |

Bloom과 Swell을 함께 켜면 두 효과 중 더 낮은 게인이 해당 잔향에 적용됩니다. Reverse-like와 Ducking은 둘 다 Wet 레벨을 줄일 수 있어 동시에 강하게 설정하면 잔향이 작게 들릴 수 있습니다. 각 효과를 하나씩 켜고 차이를 들어보세요.

## 6. 화면 읽기와 설정 저장

- **스펙트럼**은 주파수별로 Dry와 Reverb 성분을 보여 줍니다. 두 색의 이름은 화면 범례에서 확인하세요. Multiband를 열면 대역 경계도 표시됩니다.
- **Input / Output**은 입력과 출력의 피크 레벨(dBFS)입니다. **Tail**은 Wet 신호 레벨입니다. **Stereo**는 출력의 좌우 상관도입니다. +1에 가까우면 좌우가 비슷하고, 음수가 오래 유지되면 모노로 합쳤을 때 소리가 어떻게 바뀌는지 확인해 보세요.
- **Presets → Factory**에는 Hall, Room, Plate, Cloud가 있습니다. **Load**는 현재 설정을 프리셋으로 교체하므로, 작업 중인 소리는 먼저 **Save As**로 저장하세요.
- **Presets → User**에서 저장한 소리를 골라 **Load**를 누릅니다. 사용자 프리셋은 이름을 바꾸거나 휴지통으로 이동할 수 있습니다. macOS에서는 `~/Library/Application Support/pre-glow/Presets/`에 `.preglowpreset` 파일로 저장됩니다.

## 7. 바로 써볼 수 있는 설정

| 목표 | 시작점 |
| --- | --- |
| **보컬은 앞에, 잔향은 문장 사이에** | Plate → Decay 1.5–2.5초 → Wet을 소량부터 올리기 → Ducking Amount 30% → Release 300 ms. Threshold를 낮추며 목소리가 나올 때 잔향이 물러나는 지점을 찾으세요. |
| **신스 뒤에 옥타브 잔향** | Cloud → Shimmer On → Post-Reverb → Voice 1 Pitch +12 → Mix 20%. 고역이 튀면 Voice 1 Tone을 낮추세요. |
| **기타 한 음을 배경으로 유지** | Hall → 한 음을 연주 → 잔향이 충분히 생기면 Freeze → Wet으로 배경 음량 조절. 다음 음을 연주해 원음과 새 잔향이 어떻게 섞이는지 들어보세요. |

## 8. 문제가 생겼을 때

- **잔향이 안 들려요.** 트랙에 신호가 들어오는지 확인하고, DAW의 이펙트 바이패스와 PRE-GLOW의 Freeze 상태를 확인하세요. Wet을 올린 뒤 Hall 프리셋으로 비교해 보세요.
- **플러그인이 안 보여요.** ZIP을 푼 실제 번들을 형식에 맞는 경로에 넣었는지, Mac이 Apple Silicon인지 확인하고 DAW를 다시 시작하세요.
- **테스트 결과를 보내 주세요.** Mac 칩과 macOS 버전, DAW 이름과 버전, 사용 형식(AU/VST3/Standalone), 문제가 생긴 순서를 알려주면 재현에 도움이 됩니다. 오류가 떴다면 메시지도 함께 보내 주세요.
